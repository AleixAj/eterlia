# Arte original del logotipo

Los archivos que entregó el cliente. No se usan directamente en la web: de aquí
salen los tres PNG de `public/assets/`.

| Original             | Copia en la web              | Qué es                          |
| -------------------- | ---------------------------- | ------------------------------- |
| `1-clean.png`        | `assets/logo-lockup.png`     | Rosa sobre el nombre caligráfico |
| `2-clean.png`        | `assets/logo-wordmark.png`   | Solo el nombre (cabecera y pie) |
| `3-clean.png`        | `assets/rose-mark.png`       | Rosa de una línea               |

Los `-clean` son las versiones recortadas y con transparencia, que son las que
funcionan sobre el ocre. Los `-transparente` son los mismos con el lienzo
completo de 1024×559, y los sueltos (`1.png`, `2.png`, `3.png`) tienen fondo
opaco. Se conservan por si hace falta rehacer los recortes.

La caligrafía del nombre es **artwork, no una tipografía**: no existe como
fuente y no debe intentar reproducirse con una script.
